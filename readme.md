# ❀ Petale — 꽃잎처럼 가볍게 기억하기

Anki에서 영감을 받은 간격 반복(Spaced Repetition) 플래시카드 웹앱입니다.
펄 화이트 바탕에 오키드 핑크 · 세이지 그린 포인트의 부드러운 디자인으로,
학습이 부담이 아닌 정원을 가꾸는 일처럼 느껴지도록 만들었습니다.

## 실행 방법

빌드 도구가 필요 없습니다. 정적 서버로 열면 됩니다:

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## 라이브 데모

**https://vousvoyezsue-ops.github.io/New-anki/** — 푸시할 때마다
GitHub Actions가 gh-pages 브랜치로 자동 배포합니다.

## 주요 기능

### 연습 모드 (Quizlet 스타일 — SRS에 영향 없음)
- **퀴즈** — 다른 카드에서 오답을 뽑아 만드는 객관식 4지선다, 점수 화면
- **쓰기** — 직접 입력해 정답 확인 (문장부호·공백 무시 비교)
- **매치** — 짝 맞추기 타임어택, 덱별 최고 기록 저장

### 학습
- **간격 반복(SM-2)** — `다시/어려움/보통/쉬움` 4단계 평가, 버튼별 예상 복습
  간격 표시, '다시' 카드는 세션 내 재출제
- **오늘의 학습** — 모든 덱의 밀린 카드를 한 세션으로
- **하루 새 카드 한도** — 덱별 설정(기본 20), **실행 취소**(Z), 카드
  **별표/일시정지**와 목록 필터
- **카드 타입 3종**
  - 기본(앞/뒷면, 반대 방향 카드 동시 생성 옵션)
  - **빈칸 채우기(Cloze)** — `{{c1::단어}}` 문법, c1·c2… 마다 카드 자동 생성
  - **이미지 가리기(Image Occlusion)** — 이미지에 드래그로 마스크를 그리면
    마스크마다 카드 생성. '하나씩 가리기 / 전부 가리고 하나 맞히기' 모드
- **TTS 읽어주기** — 카드 내용을 음성으로 (한/영 자동 감지)
- 3D 카드 플립, 키보드 단축키(스페이스 · 1~4)

### 가져오기 / 내보내기
- **Anki .apkg 가져오기** — sql.js(WASM)로 브라우저에서 직접 파싱.
  기본·cloze 노트, 이미지 미디어까지 (신형 zstd 포맷 `.anki21b`는 미지원 —
  Anki에서 "구버전 호환" 내보내기 사용)
- **텍스트 대량 추가** — `앞면,뒷면` 또는 탭 구분, 한 줄에 한 카드
- JSON 백업 내보내기/가져오기

### 소셜 (Supabase)
- 이메일 가입/로그인, 사용자 이름으로 **친구 추가** · 요청 수락
- 친구들의 오늘 복습량 · 연속 학습일 공유 (RLS로 친구에게만 공개)

### 개인화
- **색상 팔레트 5종** — 펄 화이트(기본) · 아이보리 · 안개 라벤더 ·
  세이지 가든 · 미드나잇(다크)
- **한국어 / English** 전체 UI 전환
- 통계: 연속 학습일 · 12주 히트맵 · 누적 복습

## 구조

```
index.html        화면 구조 (홈 · 덱 · 학습 · 통계 · 친구 + 모달)
css/style.css     테마 토큰 기반 디자인 시스템 (5개 팔레트)
js/i18n.js        ko/en 문자열 테이블
js/srs.js         SM-2 간격 반복 스케줄러
js/store.js       localStorage 영속화 (덱·카드·미디어·설정)
js/occlusion.js   이미지 가리기 편집기 + 렌더러
js/apkg.js        .apkg 파서 (JSZip + sql.js)
js/social.js      Supabase 인증 · 친구 · 기록 동기화
js/app.js         화면 전환과 상호작용
vendor/           sql.js(WASM) · JSZip · supabase-js
```

## 데이터

학습 데이터는 브라우저 localStorage에 저장됩니다(이미지는 리사이즈 후
dataURL). 친구 기능 사용 시 오늘 복습 수와 연속 학습일만 서버에
동기화되며, 카드 내용은 서버로 전송되지 않습니다.
